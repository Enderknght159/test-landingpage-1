# عرض إدارة الميديا والتسويق الشامل — النادي الصيفي الشبابي

موقع تعريفي تفاعلي (صفحة واحدة، عربي RTL) مبني من ملف عرض PDF لصالح **MOZ Agency** و**جمعية الشام للأيتام**.

يحافظ على التصميم الأصلي: نفس الخطوط والألوان والهوية (خلفية عاجية، بطاقات رمادية، لمسات بنفسجية وتدرّج قوس قزح)، مع إضافة حركات عند التمرير، عدّادات أرقام، تقويم تفاعلي، وفهرس منسدل.

## التشغيل محليًا

الموقع ثابت بالكامل (HTML/CSS/JS بدون أي بناء). يكفي فتح `index.html` في المتصفح، أو تشغيل خادم محلي:

```bash
python -m http.server 4173
```

ثم فتح <http://127.0.0.1:4173/>.

## الملفات

```
index.html               كل المحتوى والأقسام (22 قسمًا مطابقًا لصفحات العرض)
assets/css/style.css     نظام التصميم، الشبكة، الحركات، والاستجابة
assets/js/app.js         التمرير، العدّادات، الفهرس، التقويمان، وتصفية الفترات
assets/fonts/            Alexandria (عربي) و Poppins (لاتيني) — محليًا بدون إنترنت
assets/favicon.svg       شعار التبويب
```

## ملاحظات

- التقويمات (تقويم العقد وتقويم المحتوى) تُبنى في المتصفح من مصفوفة تواريخ، ويمكن تعديلها من `assets/js/app.js`.
- الحركات تحترم `prefers-reduced-motion`، والموقع يعمل بدونه JavaScript لكن بدون حركات أو تقويمات مُولّدة.
- الفاصل الزمني للعقد في العرض يبدأ من تاريخ التوقيع، والتواريخ المعروضة هي التواريخ الافتراضية للعرض.
- ملف الـ PDF الأصلي غير مُضمَّن في المستودع.
